## How to run
1. Extract the project folder.
2. Open `index.html` in a browser such as Microsoft Edge.
3. Select a task card.
4. Press **Run example** (or the task-specific button).
5. Open Developer Tools with `F12` and select **Console** to view results.
6. Tasks 7 and 8 use `prompt()` and `alert()`; allow pop-ups/dialogues when prompted.
